# KilnCalc web app

This is a static Progressive Web App (PWA). It contains no server-side code.

## Free publication with GitHub Pages

1. Create a free GitHub account.
2. Create a new public repository, for example `kilncalc`.
3. Upload all files from this folder to the root of that repository.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, select `main` and `/root`, then save.
6. Open the published address in Safari on the iPhone.
7. In Safari, tap Share > Add to Home Screen.

The app saves input locally in the browser and is available offline after the first successful visit.

## Files

- index.html — complete application
- manifest.webmanifest — installation metadata
- service-worker.js — offline cache
- icon files — Home Screen icons
